# Contributing

Contributions are welcome when they improve the educational lab, documentation, reproducibility, troubleshooting, or defensive/remediation material.

Please:

1. Keep examples scoped to isolated or explicitly authorized environments.
2. Do not submit real credentials or client data.
3. Document what a new scenario teaches, how to configure it, how to validate it, how to remediate it, and how to reset it.
4. Prefer realistic AD misconfigurations over arbitrary "everything is Domain Admin" shortcuts.
5. Test scripts against a disposable lab before submitting them.
